# 0.5.0 交付验收记录

本记录描述0.5.0功能及独立交付验收。协议3；仅SC MCP LAB及独立副本实测。正式发布状态以远端v0.5.0 Release及其提交/附件清单为准。

已通过：生物属性与冲突/客户端隔离/响应丢失检查、保存重载和真实进程中断验证；统一MCP stdio覆盖建筑、环境、玩家、库存、事件及生物操作；相关建筑14项、操作10项和基础stdio3项回归。公共63工具均有桥接方法，诊断和LAB夹具不公开。默认桥接测试16项通过，82项需要显式开启游戏实测而跳过；游戏套件另行执行。

生物属性只经原生API一次性修改，无点击。健康和攻击力在测试中保存；移动速度与攻击抗性重载后恢复原生值，不自动保持。攻击抗性是含原生倍率的实际值。旧句柄及预检在重启/重载后失效，中断意图不自动重放。恢复只比较直接字段，不撤销移动、伤害、电路、消耗或自然变化。

既有环境、玩家、库存、事件、方块交互的LAB证据保留；不重做无关百万格与模板验收。lab_verified仅表示登记夹具通过，不代表全部Mod和组合兼容。加载中区域明确拒绝，不能当作空气。

独立交付核验通过：源码ZIP在新目录构建，固定SDK10.0.401与上游提交，零警告/错误；两个新环境分别完成源码安装和离线wheel安装。统一CLI部署后比较恢复通过；候选附件实际安装的MCP stdio综合验证通过。附件仅包含两个wheel、自有Mod和文档配置，不包含上游二进制。

发布流程要求核验GitHub署名、从最终提交重建及部署冒烟、同一提交正式打包与远端核验；发布结果保存在Release及工作区发布记录，避免把提交自身摘要写入源码形成循环。证据文件名和摘要见acceptance-0.5.json，原始日志含本地身份，仅留工作区。
